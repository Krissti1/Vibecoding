🐍 Mini Python Camp

Все уроки в одном файле. Python работает прямо в браузере.

Урок 1: Основы синтаксиса

Цель: Научиться выводить текст и работать с переменными.

В Python не нужны точки с запятой в конце строк. Отступы (пробелы) определяют блоки кода.

Пример кода:

name = "Алиса"
age = 25
print(f"Привет, меня зовут {name}, мне {age} лет.")

Задание: Измени переменную name на свое имя и запусти код.

Урок 2: Циклы и условия

Цель: Использовать циклы for и условия if.

Цикл for перебирает элементы. Условие if проверяет логику.

for i in range(3):
    if i % 2 == 0:
        print(f"{i} - четное")
    else:
        print(f"{i} - нечетное")

Задание: Добавь вывод сообщения "Конец цикла" после завершения цикла.

Урок 3: Функции

Цель: Создавать и вызывать функции.

Функции позволяют переиспользовать код. Они объявляются через ключевое слово def.

def greet(name):
    return f"Привет, {name}!"

message = greet("Разработчик")
print(message)

Задание: Напиши функцию square(x), которая возвращает квадрат числа x. Вызови её с числом 5.

Урок 4: Списки и методы

Цель: Работать со списками (list) и их методами.

Списки хранят упорядоченные данные. Можно добавлять элементы через .append().

fruits = ["яблоко", "банан"]
fruits.append("апельсин")
print(fruits[0]) # Вывод первого элемента

Задание: Создай список из 3 твоих любимых цветов. Добавь к нему еще один цвет через .append() и выведи весь список.

Урок 5: Итоговая задача

Задача: Напиши программу, которая запрашивает у пользователя имя (используй input()), приветствует его, а затем выводит длину имени.

Примечание: В этом браузере input() может работать нестабильно. Для теста используй жестко заданную переменную, например name = "Иван", но попробуй написать логику с input().
